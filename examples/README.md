# Example output

These files were produced by this app from `synthetic_test_video.mp4`, a 2-minute **synthetic** clip
(generated by `tests/synth.py`) with known injected events: a gunfire burst, an explosion, a police chase
(lights + siren), a silent crash and a shout. It is **not GTA footage**, so these examples show the
workflow and output format only, not detection accuracy on real gameplay.

For each clip: `.mp4` (1080x1920, H.264/AAC), `.jpg` thumbnail, `.json` metadata (three title options,
description, hashtags, hook, score and per-factor points, evidence, framing used).

Captions are absent because the synthetic video has no speech; the app never invents dialogue. The
opening hook line was turned on for these exports. Speech transcription was not run when these were made
(the build sandbox cannot download Whisper models).

`contact_sheet.png` shows one frame from each clip (blurred-background layout, chosen automatically
because the footage has a HUD at both bottom corners).
